# [TSK-00011] Multi-Scope EtherCAT Comparison (ENI, Topology, Slave & Hot Connect)

- **Feature**: `FR-00011`
- **Requirement**: `REQ-00011`
- **Status**: `DONE`

## Goal
Compare two catalog ENIs, two bus topologies, two individual slaves, or two Hot Connect groups via unified synchronized trees, horizontal linear bus strips, and dynamic "outer join" tables in CLI, REST, and Svelte UI.

## Implementation Plan

- [x] Implement `EniComparisonService` across `ENI`, `TOPOLOGY`, `SLAVE`, and `HOT_CONNECT` scopes.
- [x] Expose `/api/compare/*` via `CompareController` and `--cli compare` via `EniWorkshopCliCommand`.
- [x] Build `CompareView.svelte` with Tabulator Outer-Join grid + field delta drawer, side-by-side trees, and graphical linear bus lanes.
