# Project Reviews

This directory is organized by `YYYY/MM` and follows Quasar's structured review template:

- `[REVIEW-001.1]` Review reference structured as `REVIEW-xxxxx`.
- `[REVIEW-001.2]` Review title, description, and purpose.
- `[REVIEW-001.3]` List of reviewed code & deliverables.
- `[REVIEW-001.4]` List of reviewed features and constraints.
- `[REVIEW-001.5]` Issues found during review.
- `[REVIEW-001.6]` Issues resolved during review.
- `[REVIEW-001.7]` Open issues remaining after review.
- `[REVIEW-001.8]` Follow-up items for future reviews.
