# Constraint 0030

## Title

Java Programming Language Rules and Standards

*(Imported from Nunki CS-0030 and adapted for Java 21, EtherCAT ENI processing, MongoDB/GridFS, OPC-UA, and ZeroMQ.)*

## Description

This constraint defines the mandatory Java 21 engineering standards for **ENI Workshop**.

### 1. Robustness, Input Defenses & Null Safety
- **[CS-0030.1]** **Mandatory Precondition Defenses**: Every constructor, public method, and protected method shall validate parameters at entry.
  - **[CS-0030.1.1]** **Null Rejection**: Validate object arguments using `java.util.Objects.requireNonNull(arg, "...")`.
  - **[CS-0030.1.2]** **Range and Boundary Bounds**: Validate EtherCAT addresses (`0x0000`–`0xFFFF`), bit sizes, offsets, XML sizes, and numeric limits with `IllegalArgumentException` or `IndexOutOfBoundsException` before any state mutation.
- **[CS-0030.2]** **Absolute Null Safety in Domain Logic**: Never pass or return `null` across module boundaries. Return `Optional<T>` for absent single values and `List.of()` / `Collections.emptyList()` / empty arrays for absent collections.
- **[CS-0030.3]** **Defensive Copying at Boundaries**: Defensively copy mutable arrays (`byte[]`), lists (`List.copyOf(...)`), and maps (`Map.copyOf(...)`) in constructors and accessors.

### 2. Object-Oriented Design & Bounded Resource Execution
- **[CS-0030.4]** **Bounded Object & Stream Execution**: Streaming XML parsing (`XMLStreamReader` StAX) and bounded buffers shall be used for large ENI files (>50 MB, 350+ slaves) instead of unbounded DOM trees when streaming suffices, enforcing explicit max limits (`MAX_ENI_SLAVES`, `MAX_XML_BYTES`).
- **[CS-0030.5]** **Bounded Threading Execution Models**: Unmanaged `new Thread().start()` or `Executors.newCachedThreadPool()` are forbidden. All async OPC-UA, ZeroMQ, STOMP, and scan jobs run in bounded, explicitly sized executors with rejection policies.
- **[CS-0030.6]** **Object-Oriented Behavioral Patterns**:
  - **[CS-0030.6.1]** **State Pattern**: Model EtherCAT State Machine (INIT, PREOP, BOOT, SAFEOP, OP) transitions and Quasar connection lifecycle via State/enum-strategy abstractions.
  - **[CS-0030.6.2]** **Strategy Pattern**: Encapsulate EtherCAT validation rules (`EniValidationRule`), topology layout algorithms, and Quasar transport modes behind Strategy interfaces.
  - **[CS-0030.6.3]** **Factory Pattern**: Govern complex domain object instantiation (`EniDocument`, `EniSlave`, `SlaveCatalogEntry`) through validated static factories or builders.
- **[CS-0030.7]** **Strong Immutability & Encapsulation**: Keep fields `private` (and `final` wherever possible); establish invariants before constructors return.

### 3. Exhaustive Exception Processing & Lifecycle Management
- **[CS-0030.8]** **Exhaustive Exception Coverage**: Async workers, CLI commands, REST controllers, STOMP handlers, and OPC-UA/ZeroMQ listeners must catch, log, and translate low-level exceptions (`XMLStreamException`, `IOException`, `ZMQException`, `UaException`) into expressive domain exceptions (`EniWorkshopException`).
- **[CS-0030.9]** **Mandatory `try-with-resources`**: Every `AutoCloseable`/`Closeable` resource (StAX readers/writers, GZIP streams, GridFS streams, ZeroMQ `ZContext`/`ZMQ.Socket`) must be scoped inside `try-with-resources`.

### 4. Core Java Typing & Application Architecture
- **[CS-0030.10]** **Strong and Explicit Typing Mandate**: Local variable type inference (`var`) is strictly forbidden (enforced by Checkstyle).
- **[CS-0030.11]** **Semantic POJOs & Equality Contracts**: Domain carriers implement explicit `equals` and `hashCode` (`Objects.equals`/`Arrays.equals`) or immutable Java `record` types with defensive copies in compact constructors.
- **[CS-0030.12]** **Sealed Hierarchies**: Use `sealed` interfaces/classes for bounded AST nodes, validation diagnostics, and EtherCAT datagram types.
- **[CS-0030.13]** **Constructor Dependency Injection**: Use explicit constructor injection in Spring components; field `@Autowired` is forbidden.
- **[CS-0030.14]** **GraalVM Native Image Reachability**: Avoid unmanaged runtime reflection; keep Jackson/Picocli/Spring AOT hints clean.
- **[CS-0030.15]** **Structured Parameterized Logging**: Use SLF4J placeholders (`log.info("...", arg)`), never string concatenation in log calls.

## Verification

- Checkstyle (`checkstyle.xml`) rejects `var`, non-ASCII characters, missing Javadocs, and star imports.
- PMD (`pmd-ruleset.xml`) enforces `CloseResource`, `ReturnEmptyCollectionRatherThanNull`, and `GuardLogStatement`.
