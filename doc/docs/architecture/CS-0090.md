# Constraint 0090

## Title

Formal Javadoc, Commenting, and Traceability Standards

*(Adapted from Quasar CS-0090 Doxygen C++ standards to Java 21 Javadoc and Checkstyle.)*

## Description

This constraint governs Javadoc and inline commenting across all first-party Java packages (`src/main/java` and `src/test/java`).

### 1. Universal Coverage & Traceability
- **[CS-0090.1] Universal Javadoc Coverage**: Every package (`package-info.java`), class, interface, record, enum, constant, constructor, and `public`/`protected` method must have a valid Javadoc block (`/** ... */`).
- **[CS-0090.2] Mandatory Reference Citations**: Class and method Javadocs must cite originating references (`Requirement: REQ-XXXXX`, `Feature: FR-XXXXX`, `Task: TSK-XXXXX`, `Constraint: CS-XXXX`) and summarize compliance mechanisms (null safety, bounded loops, `try-with-resources`).

### 2. Parameter, Return & Error Contracts
- **[CS-0090.3] Complete `@param`, `@return`, and `@throws`**: Every parameter, non-void return value, and thrown exception must be documented with its role, preconditions, null-safety contract, and failure behavior.
- **[CS-0090.4] Formal Precision & ASCII Hygiene**:
  - Zero commented-out dead code.
  - Strictly 7-bit printable ASCII (`0x20`–`0x7E`, tab, newline) in Java source files (enforced by Checkstyle).
  - Never nest block comments (`/*` inside `/** ... */`).

### 3. In-Body & Control-Structure Comments
- **[CS-0090.5] In-Body Justifications**: Non-trivial methods (>5 lines) must include concise `//` comments explaining algorithmic phases, synchronization, EtherCAT register semantics, and error containment.
- **[CS-0090.6] Control Structure Rationale**: Significant `if`/`else`, `switch`, `for`/`while` bounds, and `try`/`catch` recovery blocks should include a brief `//` comment stating the invariant, bound constant, or recovery guarantee.

## Verification

- Checkstyle enforces `JavadocPackage`, `JavadocType`, `JavadocMethod`, `JavadocVariable`, `MissingJavadocMethod`, and 7-bit ASCII source compliance on every `mvn validate`.
