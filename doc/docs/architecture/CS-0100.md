# Constraint 0100

## Title

Comprehensive Testing, Determinism, Logging, and Test Documentation Standards

*(Adapted from Quasar CS-0100 C++/GoogleTest/CTest standards to Java 21, JUnit 5, AssertJ, Mockito, Playwright, and JaCoCo.)*

## Description

### 1. Coverage & Traceability
- **[CS-0100.1] Method & Branch Coverage**: All first-party domain services, parsers, validators, catalog extractors, and controllers shall be covered by JUnit 5 tests tracked via JaCoCo.
- **[CS-0100.2] Specification Traceability**: Every test class and test method must cite the requirement/feature/task (`REQ-*`, `FR-*`, `TSK-*`) it verifies.
- **[CS-0100.3] Enum & Small-Domain Completeness**: Parameterized tests (`@ParameterizedTest`, `@EnumSource`) shall exercise all enum values (`DatagramCmd`, `EsmTransition`, `MailboxProtocol`, `PortPhysics`) and boundary inputs (`0`, `max`, `max + 1`, empty, `null`).

### 2. Concurrency, Determinism & Resource Budgets
- **[CS-0100.4] Determinism**: Randomized or fuzz tests must use fixed, logged seeds (`new Random(0x51A5A100L)`).
- **[CS-0100.5] Resource & Duration Caps**: Unit/integration tests run cleanly within `< 2 GB` heap and `< 3 min` total Surefire execution, with isolated temp directories and ephemeral ports (`0`).
- **[CS-0100.6] Corpus & Dimensioning Tests**: The ENI engine must be verified against `DOR.xml`, `IPSE1.xml`, `IPSO1.xml`, representative corpus fixtures, and malformed/truncated negative fixtures.

### 3. Integration, UI & Documentation
- **[CS-0100.7] Cross-Layer & UI Testing**: REST/STOMP controllers are verified via `MockMvc`/SpringBootTest; frontend Svelte 5 components are type-checked (`npm run check`) and covered by Playwright E2E tests (`*PlaywrightTest.java`).
- **[CS-0100.8] Test Documentation**: Test architecture and sequence flows are documented in `doc/docs/` with PlantUML diagrams.

## Verification

- `mvn verify` executes Surefire unit/integration tests, JaCoCo coverage report, Checkstyle, and PMD.
