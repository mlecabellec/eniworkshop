# Constraint 0010

## Title

Project Quality Standards and Traceability

*(Imported and adapted from Nunki CS-0010 and Quasar CS-0010.)*

## Description

This constraint defines the overarching quality and traceability standards for **ENI Workshop**.

- **[CS-0010.1]** All first-party Java, TypeScript/Svelte, and C++ helper code shall be associated with a requirement, feature request, task, bug, or fix reference.
  - **[CS-0010.1.1]** Each class, interface, method, field, and logically distinct control block shall cite its associated reference(s).
  - **[CS-0010.1.2]** Traceability association shall use Javadoc tags (`@requirement`, `@feature`, `@task`, `@constraint`) or inline reference comments (`[REQ-XXXXX]`, `[FR-XXXXX]`, `[TSK-XXXXX]`, `[CS-XXXX]`).
- **[CS-0010.2]** Every requirement, feature, task, bug, and fix shall carry a unique structured identifier:
  - **[CS-0010.2.1]** Requirements: `REQ-[0-9\.]{5}` (e.g., `REQ-00001`).
  - **[CS-0010.2.2]** Feature requests: `FR-[0-9\.]{5}` (e.g., `FR-00001`).
  - **[CS-0010.2.3]** Tasks: `TSK-[0-9\.]{5}` (e.g., `TSK-00001`).
  - **[CS-0010.2.4]** Bugs: `BUG-[0-9\.]{5}`.
  - **[CS-0010.2.5]** Fixes: `FIX-[0-9\.]{5}`.
- **[CS-0010.3]** Strict License Compliance: All Maven and npm dependencies must be Apache 2.0 compatible (Apache-2.0, MIT, BSD, EPL-2.0, MPL-2.0); GPL/AGPL libraries are forbidden.

## Verification

- `mvn validate` enforces Checkstyle (`checkstyle.xml`, `failOnViolation=true`).
- `mvn verify` enforces PMD + CPD (`pmd-ruleset.xml`, `failOnViolation=true`), JUnit 5 tests, and JaCoCo coverage reporting.
- `npm run check` enforces Svelte/TypeScript type-checking during Maven `generate-resources`.
