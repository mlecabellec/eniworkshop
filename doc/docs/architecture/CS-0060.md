# Constraint 0060

## Title

High-Integrity and Deterministic Logic Standards (Java Adaptation)

*(Adapted from Quasar CS-0060; C++-only rules such as raw pointer arithmetic, C unions, and destructors are excluded or mapped to Java-equivalent constructs.)*

## Description

This constraint translates Quasar's MISRA-inspired deterministic logic rules into Java 21 idioms for industrial reliability.

- **[CS-0060.1] Non-Ignored Observer/Result Returns**: Pure observers, validation methods, and factory/result methods returning `ValidationReport`, `Optional<T>`, or `Result`-like outcomes must not have their return values silently discarded.
- **[CS-0060.2] Shadowing Prevention**: Local variables and parameters must not shadow outer class fields (enforced by Checkstyle `HiddenField`, allowing constructor/setter parameters cleanly).
- **[CS-0060.3] Total Branching**: Every `if-else if` chain should conclude with a documented `else` branch, and every `switch` must provide a `default` branch or exhaustive `sealed`/enum pattern match (enforced by Checkstyle `MissingSwitchDefault`).
- **[CS-0060.4] Safe Indexed Bounds (C++ Span Equivalent)**: Direct unchecked offset arithmetic on `byte[]` or `ByteBuffer` is prohibited; wrap EtherCAT frame/PDO byte packing inside bounds-checked helper methods.
- **[CS-0060.5] Algebraic Sum Types (C++ `std::variant` Equivalent)**: Use `sealed` interfaces and `record` subtypes instead of untyped `Object` or flag-bag structs.
- **[CS-0060.6] Deterministic Randomness**: Never use `Math.random()`. Use `java.security.SecureRandom` for security/IDs and seeded `java.util.Random(FIXED_SEED)` in deterministic tests.
- **[CS-0060.7] Bit-Field Integrity**: All EtherCAT register masks, ESM flags, and bit-level PDO packing (`BitOffs`, `BitLen`) must use explicit unsigned integer masks (`0xFFFF`, `0xFFL`) and named symbolic constants—never magic bit shifts.

## Excluded C++ Rules

- Raw pointer arithmetic (`ptr++`), `noexcept` destructors, and C-style `union` bans do not exist in Java and are intentionally omitted.

## Verification

- Enforced by Checkstyle (`HiddenField`, `MissingSwitchDefault`, `MagicNumber`) and unit boundary tests.
